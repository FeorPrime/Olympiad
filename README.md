# Olympiad

Репозиторий для олимпиадных заданий и их решений

Для успешной подачи решения необходимо:

1. Сделать форк репозитория (прям всего).
1. Создать папку `solution`.
1. Создать файл `solution/participant.md`.
1. Созданый файл заполнить по образцу `participant.md`.
1. Разместить в папке `solution` решения, называя файлы решений так же, как они называются в папке `problems`, но с расширением `.py`. Например: `01_robot.py`.
1. Запушить в форкнутый репозиторий решение.
1. Предложить PR оригинальному репозиторию через кнопку Contribute.
1. Создать Pull Request.
1. Если выскочило сообщение "Merging is blocked", значит ваше решение успешно отправлено на проверку.

* Не четкое соблюдение формальных требований ведет к мгновенной дисквалификации!
* При наличии одинаковых решений будет заситано то, которое прислано раньше.
* При выявлении любых признаков использования LLM решение будет дисквалифицировано. Для аппеляции представленное решение будет необходимо защитить.
* Очный этап будет проводится в аудитории без доступа в интернет.
